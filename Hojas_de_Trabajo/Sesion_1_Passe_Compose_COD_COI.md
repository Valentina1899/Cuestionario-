## Partie 1: Le Passé Composé

### 📚 Explication

Le passé composé est utilisé pour exprimer une action terminée dans le passé.

**Formation:**
```
AVOIR ou ÊTRE (au présent) + PARTICIPE PASSÉ
```

#### Avec AVOIR (la majorité des verbes):
- J'ai mangé
- Tu as fini
- Il a pris
- Nous avons fait
- Vous avez eu
- Ils ont voulu

#### Avec ÊTRE (verbes de mouvement et pronominaux):
**Dr Mrs Vandertrampp:**
- **D**evenir → je suis devenu(e)
- **R**evenir → je suis revenu(e)
- **M**ourir → je suis mort(e)
- **R**etourner → je suis retourné(e)
- **S**ortir → je suis sorti(e)
- **V**enir → je suis venu(e)
- **A**ller → je suis allé(e)
- **N**aître → je suis né(e)
- **D**escendre → je suis descendu(e)
- **E**ntrer → je suis entré(e)
- **R**entrer → je suis rentré(e)
- **T**omber → je suis tombé(e)
- **R**ester → je suis resté(e)
- **A**rriver → je suis arrivé(e)
- **M**onter → je suis monté(e)
- **P**artir → je suis parti(e)
- **P**asser → je suis passé(e)

#### Formation du Participe Passé:
- Verbes en **-er** → **-é** (parler → parlé)
- Verbes en **-ir** → **-i** (finir → fini)
- Verbes en **-re** → **-u** (vendre → vendu)

**Participes passés irréguliers importants:**
- avoir → eu
- être → été
- faire → fait
- prendre → pris
- voir → vu
- venir → venu
- mettre → mis
- pouvoir → pu
- vouloir → voulu
- devoir → dû

#### L'accord du participe passé:
**Avec ÊTRE:** Le participe s'accorde avec le sujet
- Elle est **allée** (féminin singulier)
- Ils sont **partis** (masculin pluriel)
- Elles sont **venues** (féminin pluriel)

**Avec AVOIR:** Le participe ne s'accorde PAS avec le sujet, MAIS il s'accorde avec le COD si celui-ci est placé AVANT le verbe
- J'ai vu la maison → La maison que j'ai **vue**
- J'ai mangé les pommes → Les pommes que j'ai **mangées**

#### La négation au passé composé:
- Je **n'**ai **pas** mangé
- Il **n'**est **pas** venu
- Nous **n'**avons **jamais** fait ça

## Partie 2: Les Pronoms COD et COI

### 📚 Explication

#### Les Pronoms COD (Complément d'Objet Direct)
Répondent à la question "qui?" ou "quoi?"

| Pronom | Signification |
|--------|---------------|
| me/m'  | moi           |
| te/t'  | toi           |
| le/l'  | lui (masculin) ou ça |
| la/l'  | elle (féminin) ou ça |
| nous   | nous          |
| vous   | vous          |
| les    | eux/elles     |

**Exemples:**
- Je regarde la télé → Je **la** regarde
- Il aime Marie → Il **l'**aime
- Nous achetons les livres → Nous **les** achetons

#### Les Pronoms COI (Complément d'Objet Indirect)
Répondent à la question "à qui?" ou "à quoi?"

| Pronom | Signification |
|--------|---------------|
| me/m'  | à moi         |
| te/t'  | à toi         |
| lui    | à lui/à elle  |
| nous   | à nous        |
| vous   | à vous        |
| leur   | à eux/à elles |

**Exemples:**
- Je parle à Marie → Je **lui** parle
- Il téléphone à ses parents → Il **leur** téléphone
- Tu écris à ton ami → Tu **lui** écris

#### Position dans la phrase:
**Présent:** Le pronom se place AVANT le verbe
- Je le vois
- Il lui parle

**Passé composé:** Le pronom se place AVANT l'auxiliaire
- Je l'ai vu
- Il lui a parlé

**Avec infinitif:** Le pronom se place AVANT l'infinitif
- Je vais le voir
- Il va lui parler

### 📖 Mini Lecture

Lisez le texte et répondez aux questions:

**Le weekend de Sophie**

Le weekend dernier, Sophie est allée à la campagne avec sa famille. Ils sont partis samedi matin très tôt. Son père a conduit la voiture pendant deux heures. Quand ils sont arrivés, Sophie a vu ses grands-parents qui les attendaient devant la maison. Elle les a embrassés avec joie. L'après-midi, Sophie et son frère sont allés à la rivière. Ils ont nagé et ils ont joué dans l'eau. Le soir, toute la famille a mangé ensemble. La grand-mère a préparé un délicieux repas. Dimanche, ils sont rentrés à la ville. Sophie était fatiguée mais contente.

**Questions:**

1. Où est-ce que Sophie est allée le weekend dernier?
2. Qui a conduit la voiture?
3. Qu'est-ce que Sophie a fait quand elle a vu ses grands-parents?
4. Où sont allés Sophie et son frère l'après-midi?
5. Qui a préparé le repas?

### 🎯 Points Clés à Retenir:

✓ Passé composé = AVOIR/ÊTRE + participe passé
✓ ÊTRE avec les verbes de mouvement (Dr Mrs Vandertrampp) et les verbes pronominaux
✓ Accord avec ÊTRE: toujours avec le sujet
✓ Accord avec AVOIR: seulement si COD avant le verbe
✓ COD: remplace l'objet direct (le, la, les)
✓ COI: remplace l'objet indirect - à + personne (lui, leur)
✓ Position: avant le verbe conjugué ou l'auxiliaire
