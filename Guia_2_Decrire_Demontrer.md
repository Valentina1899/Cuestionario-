# Guide 2: Decrire et Demontrer

## Les Adjectifs Demonstratifs

### Formation et usage

Les adjectifs demonstratifs designent une personne ou une chose proche ou eloignee.

**Formes:**

| Masculin singulier | Feminin singulier | Pluriel (m/f) |
|-------------------|-------------------|---------------|
| ce (consonne) | cette | ces |
| cet (voyelle/h muet) | cette | ces |

**Exemples:**
- ce livre (ce + consonne)
- cet homme (cet + h muet)
- cet ami (cet + voyelle)
- cette femme
- cette histoire
- ces livres
- ces femmes

### Usage specifique

**Pour insister sur la proximite ou la distance:**
- ce livre-ci (ce livre ici, proche)
- ce livre-la (ce livre la-bas, eloigne)

**Difference avec l'article defini:**
- le livre = un livre en general
- ce livre = un livre specifique que je montre

## C'est vs Il est / Elle est

### Regles d'utilisation

**C'EST + article + nom (avec ou sans adjectif):**
- C'est un medecin. (profession avec article)
- C'est un bon medecin.
- C'est une voiture.
- C'est la voiture de Paul.
- C'est mon frere.

**C'EST + adjectif (commentaire general):**
- C'est interessant.
- C'est difficile.
- C'est vrai.
- C'est important.

**IL EST / ELLE EST + adjectif (description d'une personne/chose):**
- Il est grand. (description de Pierre)
- Elle est intelligente. (description de Marie)
- Il est rouge. (description du livre)

**IL EST / ELLE EST + profession (sans article):**
- Il est medecin.
- Elle est professeur.
- Il est ingenieur.

**ILS SONT / ELLES SONT (pluriel):**
- Ils sont medecins.
- Elles sont grandes.
- Ils sont francais.

### Schema recapitulatif

```
C'EST + article + nom
C'EST + adjectif (commentaire general)
C'EST + nom propre

IL/ELLE EST + adjectif (description)
IL/ELLE EST + profession (sans article)
IL/ELLE EST + nationalite (sans article)
```

## Les Articles Contractes

### Formation

**DE + article defini:**
- de + le = du (Je viens du marche)
- de + la = de la (Je viens de la poste)
- de + l' = de l' (Je viens de l'ecole)
- de + les = des (Je viens des magasins)

**A + article defini:**
- a + le = au (Je vais au cinema)
- a + la = a la (Je vais a la piscine)
- a + l' = a l' (Je vais a l'hopital)
- a + les = aux (Je vais aux toilettes)

### Usages principaux

**Avec DE:**
- Provenance: Je viens du supermarche.
- Possession: C'est le livre du professeur.
- Composition: Un verre d'eau, une tasse de cafe.

**Avec A:**
- Direction: Je vais au parc.
- Localisation: Il habite a la campagne.
- Fonction: Une machine a laver.

## Les Adverbes de Quantite

### Liste des principaux adverbes

**Adverbes + DE/D' (sans article):**

| Adverbe | Signification | Exemple |
|---------|---------------|---------|
| beaucoup de | mucho/a | J'ai beaucoup d'amis. |
| un peu de | un poco de | Je veux un peu de sucre. |
| assez de | bastante | Nous avons assez de temps. |
| trop de | demasiado/a | Il y a trop de bruit. |
| pas assez de | no bastante | Il n'y a pas assez de place. |
| plus de | mas de | Je veux plus de cafe. |
| moins de | menos de | Elle mange moins de pain. |
| autant de | tanto/a | Il a autant de livres que moi. |
| plein de | lleno de | J'ai plein d'idees. |
| tant de | tanto/a | Il y a tant de choses a faire. |
| peu de | poco/a | Il a peu d'argent. |
| combien de | cuanto/a | Combien de temps? |
| plusieurs | varios/as | J'ai plusieurs freres. |
| quelques | algunos/as | Il a quelques amis. |

**Attention:**
- plusieurs et quelques ne prennent PAS "de"
- plusieurs livres (pas: plusieurs de livres)
- quelques amis (pas: quelques d'amis)

## Le Corps Humain

### Vocabulaire du corps

**La tete:**
- la tete (head)
- le visage (face)
- les cheveux (hair)
- le front (forehead)
- les yeux / un oeil (eyes / eye)
- le nez (nose)
- la bouche (mouth)
- les levres (lips)
- les dents (teeth)
- la langue (tongue)
- les oreilles (ears)
- le cou (neck)
- le menton (chin)
- la joue (cheek)

**Le tronc:**
- les epaules (shoulders)
- le dos (back)
- la poitrine (chest)
- le ventre (belly)
- le coeur (heart)
- les poumons (lungs)
- l'estomac (stomach)

**Les membres:**
- le bras (arm)
- le coude (elbow)
- la main (hand)
- les doigts (fingers)
- le pouce (thumb)
- la jambe (leg)
- le genou (knee)
- le pied (foot)
- les orteils (toes)
- la cheville (ankle)

### Expressions avec le corps

- avoir mal a la tete (avoir mal au/a la + partie du corps)
- se faire mal (hacerse dano)
- se casser la jambe (romperse la pierna)
- se couper le doigt (cortarse el dedo)
- se bruler la main (quemarse la mano)

## La Sante et les Maladies

### Vocabulaire medical

**Etre malade:**
- etre malade (estar enfermo)
- se sentir mal (sentirse mal)
- ne pas se sentir bien
- aller chez le medecin
- prendre rendez-vous

**Les maladies courantes:**
- un rhume (un resfriado)
- la grippe (la gripe)
- une angine (una angina)
- la fievre (la fiebre)
- une allergie (una alergia)
- une infection (una infeccion)
- un mal de tete (un dolor de cabeza)
- un mal de ventre (un dolor de estomago)
- un mal de gorge (un dolor de garganta)

**Les symptomes:**
- avoir de la fievre (tener fiebre)
- tousser (toser)
- eternuer (estornudar)
- avoir le nez qui coule (tener mocos)
- avoir mal a... (tener dolor de...)
- etre fatigue(e) (estar cansado/a)
- avoir des nausees (tener nauseas)
- vomir (vomitar)
- avoir des vertiges (tener mareos)

**Les remedes:**
- un medicament (una medicina)
- un comprime / une pilule (una pastilla)
- un sirop (un jarabe)
- une piqure (una inyeccion)
- du repos (descanso)
- boire beaucoup d'eau
- prendre des vitamines
- se reposer (descansar)
- guerir (curarse)

### Verbes utiles

- tomber malade (caer enfermo)
- attraper un rhume (coger un resfriado)
- se soigner (cuidarse)
- guerir (curarse)
- aller mieux (estar mejor)
- se retablir (recuperarse)

### Exercice 12: Dialogue chez le medecin
