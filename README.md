# Plan de Estudio - Examen de Francés B1

## 📚 Descripción del Proyecto

Este repositorio contiene un **plan de estudio completo** para preparar un examen de francés nivel B1 diseñado para un estudiante masculino de 15 años en grado décimo. El programa incluye 5 sesiones de una hora cada una, con hojas de trabajo detalladas y simulacros de examen.

## 🎯 Objetivos del Examen

El examen consta de **10 preguntas** que evalúan:
- ✅ Interpretación de textos
- ✅ Manejo de gramática
- ✅ Producción escrita

Todo el material está completamente en francés.

## 📖 Temas Cubiertos

1. **Le passé composé** (tema fundamental)
2. L'imparfait
3. Les pronoms COD (Complément d'Objet Direct)
4. Les pronoms COI (Complément d'Objet Indirect)
5. Le pronom "en"
6. Les verbes du premier groupe (-er)
7. Les verbes du deuxième groupe (-ir)
8. Les verbes du troisième groupe (irréguliers)
9. Le futur proche
10. Le passé récent
11. Le présent progressif
12. Les pronoms relatifs (qui, que, où)

## 🗓️ Planificación de las Sesiones

### **Sesión 1** (1 hora)
- **Tema:** Le Passé Composé et les Pronoms COD/COI
- **Material:** Hoja de Trabajo 1 + Simulacro 1

### **Sesión 2** (1 hora)
- **Tema:** L'Imparfait et le Pronom "En"
- **Material:** Hoja de Trabajo 2 + Simulacro 2

### **Sesión 3** (1 hora)
- **Tema:** Les Temps Progressifs (Futur Proche, Passé Récent, Présent Progressif)
- **Material:** Hoja de Trabajo 3 + Simulacro 3

### **Sesión 4** (1 hora)
- **Tema:** Les Groupes de Verbes et les Pronoms Relatifs
- **Material:** Hoja de Trabajo 4 + Simulacro 4

### **Sesión 5** (1 hora)
- **Tema:** Révision Complète et Examen Blanc
- **Material:** Hoja de Trabajo 5 + Simulacro 5 (Examen completo de 10 preguntas)

## 📝 Características de los Materiales

### Hojas de Trabajo
Cada hoja de trabajo incluye:
- 📚 **Explicaciones gramaticales claras** en francés
- ✏️ **Ejercicios prácticos** con diferentes niveles de dificultad
- 📖 **Textos de lectura** para practicar la comprensión
- 🎯 **Resúmenes de puntos clave**
- 💡 **Consejos útiles** para el aprendizaje

### Simulacros
Cada simulacro contiene:
- 📋 Formato similar al examen real
- ⏱️ Tiempo sugerido de realización
- 📊 Baremo de calificación
- ✅ Diferentes tipos de ejercicios (comprensión, gramática, producción)

## 🎓 Criterios de Evaluación

### Compréhension écrite (30%)
- Comprensión de la idea principal
- Identificación de detalles específicos
- Capacidad de inferencia

### Grammaire (40%)
- Uso correcto de tiempos verbales
- Concordancia del participio pasado
- Uso adecuado de pronombres
- Conjugación correcta

### Production écrite (30%)
- Coherencia y organización
- Riqueza de vocabulario
- Corrección gramatical
- Ortografía

## 💡 Consejos para el Estudiante

### Antes del examen:
- ✅ Revisar las conjugaciones diariamente
- ✅ Leer textos cortos en francés
- ✅ Practicar la escritura de párrafos cortos
- ✅ Prestar atención a las concordancias

### Durante el examen:
- ✅ Leer atentamente cada pregunta
- ✅ Gestionar el tiempo (aproximadamente 6 minutos por pregunta)
- ✅ Verificar las concordancias del participio pasado
- ✅ Releer las producciones escritas

## 🚀 Cómo Usar Este Material

1. **Empieza por leer** el `Plan_de_Estudio.md` para entender la estructura completa
2. **Sigue las sesiones en orden**, dedicando una hora a cada una
3. **Estudia** la hoja de trabajo correspondiente a cada sesión
4. **Practica** con el simulacro después de estudiar cada tema
5. **Finaliza** con el Simulacro 5, que es un examen completo

## 📌 Nota Importante

Este material está diseñado específicamente para el nivel B1 del Marco Común Europeo de Referencia para las Lenguas (MCERL). Se enfoca en los temas más relevantes para este nivel y proporciona práctica intensiva en las áreas clave.
